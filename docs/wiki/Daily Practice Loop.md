# Daily Practice Loop

The **keystone retention feature** (see [[Learning Philosophy]]): a short daily
ritual that bundles everything we've built into one repeatable, rewarding session.
Status: **session runner + streak built (the "Today" home tab); onboarding next.**

## The session — "Today"
One tap from launch → a short (~5 min, ~4–5 blocks) guided sequence the app picks
(offload "what to do" — the Anki/Duolingo principle). Each block reuses an existing
tool, pre-targeted:

1. **Tune** — always first; instant win and genuinely needed. ([[Tuner]])
2. **Warm-up / review** — one decay-due skill resurfaced (spaced repetition).
3. **Focus** — the coach's top "weakest-but-ready" skill, via [[Chord Detection|Chord Check]] or the [[Rhythm Mode|drill]].
4. **Stretch** — one slightly harder / new skill if prerequisites are met (ZPD).
5. **End on a win** — close with something already mastered, so the session ends
   on success. *Always finish positive.*

Clear start/end, a progress indicator (block 3 of 5), and a celebratory finish
(*"Nice — day 4! 🔥"*). Generated by `SelectionPolicy` (decay-due → review,
weakest-but-ready → focus, mastered → closing win), so it mostly orchestrates
systems that already exist.

## First-session onboarding (manufacture the win)
With no observations yet, the first run is scripted to guarantee success:
1. Set the expectation — *"5 minutes a day."*
2. Tune together (the app does most of it → guaranteed success).
3. *"Play your first chord"* — Em (2 fingers, easiest) → guided → strum →
   *"Clean! You just played your first chord."* — **the win**.
4. Offer a daily reminder time (the cue) + goal.
This both **seeds the coach** (cold-start priors) and delivers the early win.

## Habit mechanics
- **Streak** — consecutive days with a completed session, shown prominently.
- **Forgiveness** — a limited auto streak-freeze so one missed day doesn't reset;
  "welcome back," not "you broke it." Decay resurfaces review gently, never as punishment.
- **Tiny minimum** — even a 1-block session counts (2-minute rule).
- **Reminder** — a daily notification at the chosen time (needs notification
  permission; may be deferred).

## Architecture
- **Session generator** (pure, testable): mastery states + graph → ordered list of
  blocks. Reuses [[The Coach]]'s selection logic.
- **Streak logic** (pure, testable): set of completed-session dates → current streak
  (+ freeze). Persisted in UserDefaults or the log.
- Each block launches the relevant tool pre-targeted; observations already flow to
  the coach.
